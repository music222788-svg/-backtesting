- 작성일: 2026-09-18
- 근거 백테스트: `cs2026/` (데이터 다운로드일 2026-09-17, 가격 최종일 2026-09-16)

## 2. 운용 규칙

### 2.1 두 날짜만 기억한다

| 날짜 | 할 일 |
|---|---|
| **매년 12월 마지막 거래일 (점검일)** | 종가 기준 비중을 **기록만** 한다. 매매하지 않는다. |
| **그 다음 거래일 (체결일)** | 점검일에 내린 판정대로 **종가에 매매를 체결**한다. |

체결일은 "다음 날"이 아니라 **다음 거래일**이다. 주말·휴장을 건너뛴다(실제로 2~5일 간격이었다).

### 2.2 점검일에 판정할 것 — 코어 5/25 밴드

코어 4개 자산의 **코어 합계 대비** 비중을 계산한다. 하나라도 아래 범위를 벗어나면 "밴드 이탈"이다.

| 자산 | 목표(코어 내) | 허용 범위(코어 내) |
|---|---|---|
| SPY | 60% | **55% ~ 65%** |
| SCHD | 20% | **15% ~ 25%** |
| IEF | 10% | **7.5% ~ 12.5%** |
| GLD | 10% | **7.5% ~ 12.5%** |

> 주의: 밴드는 **전체 자산이 아니라 코어 합계**를 분모로 계산한다.

### 2.3 체결일에 실행할 것

체결일 **종가 기준 전체 평가액 V**를 구한 뒤 순서대로 계산한다.

1. **최상위 복원 (P3는 매년 무조건 실행)**
   - 코어 목표 합계 = **0.70 × V**
   - 위성 목표 합계 = **0.30 × V**

2. **코어 내부**
   - 점검일에 **밴드 이탈이 있었으면** → SPY / SCHD / IEF / GLD = 코어 목표 합계의 **60 / 20 / 10 / 10**
   - 점검일에 **밴드 이탈이 없었으면** → **현재 코어 내부 비율을 그대로 유지**한 채 코어 합계만 0.70×V로 맞춘다 (코어 내부는 건드리지 않는다)

3. **위성 내부 (매년 무조건 실행)**
   - TQQQ / SGOV = 위성 목표 합계의 **60 / 40**

## 3. 계산 예시

### 예시 A — 밴드 이탈이 있는 경우

점검일 종가 평가액:

| 자산 | 금액 | 코어 내 비중 | 판정 |
|---|---|---|---|
| SPY | $52,000 | 63.4% | 정상 (55~65) |
| SCHD | $15,000 | 18.3% | 정상 (15~25) |
| IEF | $6,000 | **7.3%** | **이탈** (7.5~12.5) |
| GLD | $9,000 | 11.0% | 정상 |
| 코어 합계 | $82,000 | | |
| TQQQ | $30,000 | | |
| SGOV | $8,000 | | |
| 위성 합계 | $38,000 | | |
| **전체 V** | **$120,000** | | **→ 밴드 이탈 있음** |

체결일 (평가액 변동 없다고 가정, V = $120,000):

| 자산 | 목표 금액 | 계산 |
|---|---|---|
| SPY | $50,400 | 120,000 × 0.70 × 0.60 |
| SCHD | $16,800 | × 0.70 × 0.20 |
| IEF | $8,400 | × 0.70 × 0.10 |
| GLD | $8,400 | × 0.70 × 0.10 |
| TQQQ | $21,600 | × 0.30 × 0.60 |
| SGOV | $14,400 | × 0.30 × 0.40 |

### 예시 B — 밴드 이탈이 없는 경우

점검일: SPY $51,000 / SCHD $15,000 / IEF $7,000 / GLD $7,000 (코어 $80,000)
→ 코어 내 비중 63.75% / 18.75% / 8.75% / 8.75% → **전부 정상, 이탈 없음**
위성: TQQQ $30,000 / SGOV $10,000 (위성 $40,000). V = $120,000.

체결일:

| 자산 | 목표 금액 | 계산 |
|---|---|---|
| SPY | $53,550 | 84,000 × 0.6375 (**현재 비율 유지**) |
| SCHD | $15,750 | 84,000 × 0.1875 |
| IEF | $7,350 | 84,000 × 0.0875 |
| GLD | $7,350 | 84,000 × 0.0875 |
| TQQQ | $21,600 | 36,000 × 0.60 (**항상 복원**) |
| SGOV | $14,400 | 36,000 × 0.40 |

코어 합계만 $80,000 → $84,000으로 늘리고 **코어 내부 구성은 손대지 않는다**. 위성은 이탈 여부와 무관하게 매년 60/40으로 되돌린다.

## 4. 연말 실행 체크리스트

```
[점검일 — 12월 마지막 거래일 종가]
□ 6개 자산 평가액 기록
□ 코어 합계 / 위성 합계 계산
□ 코어 내부 비중 4개 계산 → 밴드 이탈 여부 판정 (Y/N) 기록
□ 매매하지 않음

[체결일 — 다음 거래일]
□ 종가 기준 전체 평가액 V 재계산
□ 코어 목표 = 0.70V, 위성 목표 = 0.30V
□ 코어 내부: 이탈 Y → 60/20/10/10 / 이탈 N → 현재 비율 유지
□ 위성 내부: TQQQ 60 / SGOV 40 (무조건)
□ 종가에 체결 (장 마감 직전 주문)
□ 체결 내역·실현손익 기록

[다음 해 5월]
□ 해외주식 양도소득세 확정신고
```

## 5. 비용·세금 전제 (백테스트에 반영된 값)

| 항목 | 값 |
|---|---|
| 거래비용 + 슬리피지 | 편도 합계 **0.10%** (매수·매도 각각), 최초 편입에도 부과 |
| 양도소득세 | 실현 양도차익에 **22%** (양도세 20% + 지방소득세 2%) |
| 기본공제 | 연 **250만원** (포트폴리오 전체 기준 연 1회) |
| 손익 통산 | 연간 통산, **손실 이월공제 없음** |
| 취득원가 | **이동평균법** |
| 매매 수수료 | 매도 수수료는 양도차익에서 공제, 매수 수수료는 취득원가에 산입 |

실제 매매 빈도 (백테스트 실측):

| 구간 | 체결일 수 | 종목 매매 건수 | 연평균 |
|---|---|---|---|
| 2000–2019 (20년) | 19회 | 114건 | 연 0.95회 / 5.7건 |
| 2020–2026 (6.7년) | 6회 | 36건 | 연 0.90회 / 5.4건 |

위성 60/40 복원이 매년 무조건 발동하므로 **사실상 매년 1회, 6종목 전부 손보는 구조**다.

## 7. 이 선택으로 감수하는 것 (백테스트에서 실제로 확인된 위험)

### 7.1 10년 넘게 전고점을 못 넘긴 적이 있다
2000-03-24 고점 이후 **2,694거래일(10.7년)** 동안 원금 회복이 안 됐다. 같은 기간 코어100은 5.3년, SPY는 6.6년이었다. 2000–2002 3년 누적 **−52.4%**.

### 7.2 위성이 사실상 전멸해도 매년 30%로 되사야 한다
합성 TQQQ는 2001-08-30에 원금의 1% 아래로 떨어졌고 2009-03-09에 **원금의 0.042%**까지 갔다. P3가 구간 A에서 1위인 이유는 그 상태에서도 **매년 전체의 18%를 TQQQ에 다시 채워 넣어** 2010년대 상승을 온전히 탔기 때문이다.
**이 규칙을 중간에 포기하면 백테스트 결과와 무관한 포트폴리오가 된다.** 가장 사기가 꺾이는 시점(위성이 −99%)에 가장 많이 사야 하는 구조다.

### 7.3 그 위성이 상장폐지되면 P3는 꼴찌가 된다

| 시나리오 | 구간 A CAGR | 구간 A 순위 | 최종자산 |
|---|---|---|---|
| 기본 (TQQQ 존속) | 7.99% | **1위** | $46,320 |
| 2001-08-30 이후 TQQQ=0 | **4.27%** | **7위 (꼴찌)** | $23,022 |

원금의 0.04%까지 떨어진 3배 ETF가 청산되지 않고 계속 거래된다는 전제가 P3의 1위를 떠받치고 있다.

### 7.4 블록 부트스트랩: 43.5% 경로에서 위성이 붕괴했다
1,000회 재표본 중 **구간 A 43.5%, 구간 C 34.8%**의 경로에서 합성 3배가 원금 1% 미만으로 붕괴했다. 붕괴 경로만 보면 P3의 CAGR 중앙값은 **4.18%**로 코어100(4.58%)보다 낮았다.

| 구간 A 부트스트랩 | P3 | 코어100 참고 |
|---|---|---|
| CAGR 중앙값 | 7.87% | 6.64% |
| CAGR 하위 10% | 1.29% | 2.64% |
| CAGR 음수 비율 | 5.3% | 2.4% |
| MDD 중앙값 | −51.5% | −39.2% |
| MDD 하위 10% | −69.7% | −53.4% |

### 7.5 근거 데이터 자체의 한계
- 2000–2010년 TQQQ는 **전부 합성값**이다. 실제로 그 시기에 3배 레버리지 ETF는 존재하지 않았다.
- 합성 TQQQ는 실제 TQQQ 대비 **연 +2.38pp 과대**이고, 17개 연도 전부 같은 방향이다.
- 구간 A의 2000–2001년은 P3 자산의 **58%가 프록시**다.
- 구간 C에서 코어의 성과를 끌어올린 1등 자산은 **금(CAGR 10.18%)** 이다. 금값이 26년간 15.3배가 된 예외적 구간이었다.

|---|---|
